# VANTIQ - Premium Trading Signals Platform

**Precision. Intelligence. Market Edge.**

A professional trading signals platform built as a Telegram Mini App with Firebase hosting and Supabase backend.

## 🚀 Features

- **Premium Trading Signals** - Professional signals with entry, stop loss, and take profit levels
- **Multi-Market Support** - Crypto, Forex, Gold, Indices, and more
- **Real-time Performance Tracking** - Transparent statistics and analytics
- **Cryptocurrency Payments** - Secure on-chain payment verification
- **Telegram Integration** - Native Mini App experience
- **Beautiful UI** - Premium dark theme with smooth animations

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Framer Motion
- **Backend**: Supabase (PostgreSQL + Realtime + Auth)
- **Hosting**: Firebase Hosting
- **Payments**: Cryptocurrency (BTC, ETH, USDT, etc.)
- **Bot**: Telegram Bot API
